ACVS credential verifier

Checks an academic credential file against a public blockchain. It does not contact the university's server, and the file never leaves this page.

1. The credential file

The credential.json or credential-full.json file the graduate gave you.

No file to hand? Try an example, a fictional credential anchored on Sepolia: full file (proves every field) or public file.

2. Where to check it

Any public node of this network works. Only hashes and positions are sent to it, never a name.

What the file says

Checks

    A personal (security-key) countersignature and the university's internal rules on signing order are not checked here; the university's own verification page covers those.
